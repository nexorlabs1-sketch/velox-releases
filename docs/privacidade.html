Política de Privacidade

Esta página descreve o tratamento de dados pelo instalador visual do Sistema de Gestão VeloX, mantido pelo canal técnico nexorlabs1-sketch/velox-releases.

Finalidade e dados usados

O instalador usa o identificador e o e-mail verificado da conta Google para reconhecer o proprietário e localizar a instalação criada por este aplicativo. Usa os identificadores das pastas, banco de dados, projeto e implantação para preparar e recuperar essa instalação. A senha da conta não é solicitada nem recebida pelo VeloX.

Permissões do Google

O Google solicita acesso aos arquivos do Drive usados com o instalador, à criação e atualização de projetos Apps Script e às suas implantações. O instalador utiliza essas permissões para criar e verificar o VeloX privado do usuário; não modifica projetos alheios à instalação. A permissão de projetos solicitada pelo Google é mais ampla que um único projeto, conforme a tela oficial de consentimento.

Armazenamento e duração

O token de autorização, o identificador e o e-mail ficam temporariamente no cache protegido do projeto central, por no máximo 50 minutos de validade da sessão. O instalador não solicita token de renovação. Uma nova autorização pode ser necessária para retomar após a expiração.

O registro de recuperação e a configuração do sistema permanecem em arquivos privados na conta Google do proprietário. Contêm os identificadores da própria instalação e o e-mail do proprietário. Os cadastros e documentos do sistema instalado ficam na conta do cliente, sem cópia automática para uma base central do mantenedor.

Compartilhamento e proteção

As operações de autenticação, criação, armazenamento e publicação usam os serviços oficiais do Google por HTTPS. O projeto central processa a autorização temporária e os metadados necessários à instalação. Seus editores técnicos podem administrar esse projeto. O sistema instalado é publicado com acesso somente ao proprietário.

O canal público do GitHub fornece os arquivos públicos de atualização quando o usuário solicita a verificação de novidades. Os cadastros e documentos privados não são enviados ao GitHub. Não há publicidade nem uso dos dados Google para treinamento de modelos de inteligência artificial pelo instalador.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado. O Google e o GitHub podem manter registros técnicos conforme suas próprias políticas.

Controle, revogação e remoção

O usuário pode revogar o acesso nas conexões da Conta do Google. Isso impede novas operações com a autorização revogada, sem apagar os arquivos já criados. O cache da sessão expira automaticamente. Os arquivos e a implantação pertencem ao usuário e podem ser administrados ou removidos na própria conta Google.

Contato e mudanças

Para dúvidas sobre autorização e privacidade, utilize o e-mail de suporte apresentado na tela oficial de consentimento do aplicativo, ou o canal técnico público. Não publique dados pessoais, documentos ou credenciais em relatos públicos. Mudanças no uso de dados devem ser informadas antes de solicitar nova autorização.
